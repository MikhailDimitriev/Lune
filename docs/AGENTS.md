Сайт двухцветный - один золотой(в app.css 2 класса) и черный. Люксовый сайт драгоценных украшений. 

При создании компонента по архитектуре FSD создавай слайс в определенном слое, если компонент содержит логику то создавай папки model и ui, так же создавай public api и сам компонент помещай в папку ui далее в папку с названием компонента, так же в этой папке создавай public api
Создавай компоненты не через Function Declaration, а через анонимную стрелочную функцию.
При создании компонентов создавай public api

Выполняй по одному компоненту и отмечай те файлы, в которые ты внес изменения.
